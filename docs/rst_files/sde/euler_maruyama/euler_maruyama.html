Euler-Maruyama Method Documentation¶

This module implements the Euler-Maruyama method for simulating stochastic differential equations (SDEs):

\(dX_t = \mu(X_t, t) dt + \sigma(X_t, t) dW_t\)

where:

  • \(X_t\) is the state variable at time \(t\), it is a stochastic process taking values in \(\mathbb{R}^n\)

  • \(\mu\) is the drift coefficient, a function \(\mu: \mathbb{R}^n \times \mathbb{R}^+ \to \mathbb{R}^n\)

  • \(\sigma\) is the diffusion coefficient, a function \(\sigma: \mathbb{R}^n \times \mathbb{R}^+ \to \mathbb{R}^n\)

  • \(W_t\) is a Wiener process (or Brownian motion) in \(\mathbb{R}^n\).

The Euler-Maruyama method is a numerical technique used to approximate solutions to stochastic differential equations. It is an extension of the Euler method for ordinary differential equations, incorporating stochastic components.

The method discretizes the time interval \([0, T]\) into \(N\) steps of size \(\Delta t = T/N\). At each time step, the state variable is updated according to the formula:

\(X_{t+\Delta t} = X_t + \mu(X_t, t) \Delta t + \sigma(X_t, t) \Delta W_t\)

where \(\Delta W_t\) is a normally distributed random variable with mean \(0\) and variance \(\Delta t\), representing an increment of the Wiener process.

The method also requires the initial condition \(X_0\), which is typically sampled from a specified distribution.

Error Analysis¶

The strong error of the Euler-Maruyama method is defined as the expected value of the absolute difference between the true solution \(X_T\) and the numerical approximation \(X_T^{\Delta t}\) at time \(T\):

\(E\left[\left\|X_T(W_t) - X_T^{\Delta t}(W_t)\right\|^2\right]\)

where:

  • \(X_T(W_t)\) is the exact solution of the SDE at time \(T\) given the Wiener process \(W_t\),

  • \(X_T^{\Delta t}(W_t)\) is the approximation obtained using the Euler-Maruyama method with time step \(\Delta t\) via Wiener process \(W_t\).

Under this definition, the Euler-Maruyama method exhibits the Euler-Maruyama method has a strong convergence order of \(0.5\), meaning that the error decreases proportionally to \(\sqrt{\Delta t}\) as the time step \(\Delta t\) approaches zero.

The weak error is defined in terms of the expected value of a test function \(\phi\) applied to the solution:

\(\left|E\left[\phi(X_T(W_t))\right] - E\left[\phi(X_T^{\Delta t}(W_t))\right]\right|\)

For the weak error, the Euler-Maruyama method has a convergence order of \(1\), meaning that the error decreases proportionally to \(\Delta t\) as the time step \(\Delta t\) approaches zero. Consequently, the Euler-Maruyama method is particularly effective for approximating expectations of functionals of the solution, which is often the primary interest in applications involving SDEs.

Implements the Euler-Maruyama scheme for simulating stochastic differential equations (SDEs).

SDE Model:

\(dX_t = dt\text{drift}(X_t, t) + \text{diffusion}(X_t, t) dW_t \quad X_t\in\mathbb{R}^{d}\)

where \(W_t\) is a standard Wiener process in \(\mathbb{R}^{d}\), \(\text{drift}\in\mathbb{R}^{d}\), \(\text{diffusion}\in\mathbb{R}^{d\times d}\).

Euler-Maruyama Update:

\(X_{t+dt} = X_t + dt\text{drift}(X_t, t) + \text{diffusion}(X_t, t) \Delta W_t\)

where \(\Delta W_t \sim \mathcal{N}(0, dt I_d)\).
