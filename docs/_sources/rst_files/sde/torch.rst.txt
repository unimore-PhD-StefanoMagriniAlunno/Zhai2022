Troch SDE Support
=================

This module provides support for defining and simulating Stochastic Differential Equations (SDEs) using PyTorch tensors.
It includes a class for representing SDE models and an implementation of the Euler-Maruyama method for numerical simulation.

See also the main SDE documentation.
